## 🧾 Overview  
**Expense Tracker App** is a powerful Flutter + Firebase application that helps users manage personal finances easily.  
Add, edit, and categorize your transactions, view your spending patterns, and sync data securely across devices using Firebase.  

---

## 🚀 Features  
✨ Add, edit, and delete transactions  
💸 Categorize income and expenses  
📊 View total income, expenses, and balance  
☁️ Firebase Firestore integration for real-time sync  
🔐 Firebase Authentication (Email/Google login)  
📆 Filter and search transactions by date or category  
📱 Clean and responsive UI for all platforms  
🌙 Light and dark mode support  

---

## 🛠️ Tech Stack  
| Technology | Description |
|-------------|-------------|
| **Flutter** | Cross-platform UI framework |
| **Dart** | Programming language |
| **Firebase Authentication** | Secure user login & signup |
| **Cloud Firestore** | Realtime database for storing transactions |
| **Firebase Storage** | For uploading and managing user files (optional) |

| **Android Studio / VS Code** | IDEs used for development |

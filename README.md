## 🧾 Overview  
**Expense Tracker App** is a Flutter-based personal finance management tool that helps you record your daily income and expenses with ease.  
You can categorize transactions, view detailed charts, and monitor your financial health in a clean, intuitive interface.

---

## 🚀 Features  
- ✨ Add, edit, and delete transactions easily  
- 📂 Categorize income and expenses  
- 📆 Filter by date or category  
- 📊 Beautiful charts and spending insights  
- 💾 Local data storage using SQLite / Hive  
- 🎨 Clean, responsive UI built with Flutter  
- 🔔 Optional reminders for upcoming expenses (future update)
